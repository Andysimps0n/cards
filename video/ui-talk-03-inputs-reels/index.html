UI 용어 ①

Dropdown

[드롭다운]

누르면 목록이 펼쳐지고 하나를 고르는 칸이에요.

고를 게 많아서 화면에 다 펼치기 어려울 때 써요.

✏️ 팁 고를 게 몇 개뿐이면 다 펼쳐 둔 Radio Button이 더 편할 수 있어요.
UI 용어 ②

Toggle

[토글]

켜짐과 꺼짐을 바로 바꾸는 스위치예요.

알림, 다크 모드처럼 누르는 즉시 적용되는 설정에 써요.

✏️ 팁 Toggle은 누르면 바로 적용, Checkbox는 저장을 눌러야 적용돼요.
UI 용어 ③

Checkbox

[체크박스]

여러 개를 동시에 고르는 네모 칸이에요.

관심사, 약관 동의처럼 하나 이상 고를 때 써요.

✏️ 팁 여러 개 고르면 Checkbox, 하나만 고르면 Radio Button이에요.
UI 용어 ④

Radio Button

[라디오 버튼]

여러 개 중 딱 하나만 고르는 동그라미예요.

배송 방법처럼 하나만 골라야 할 때 써요.

✏️ 팁 동그라미는 하나만, 네모는 여러 개. 모양으로 기억해요.
UI 용어 ⑤

Date Picker

[데이트 피커]

달력을 띄워 날짜를 고르는 입력칸이에요.

예약일, 생일처럼 날짜를 받을 때 써요.

✏️ 팁 기간을 고를 땐 "시작일과 종료일을 Date Picker로"라고 말해요.
