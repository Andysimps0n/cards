# AI가 알아먹는 UI 용어집 1탄 캡션

화면 위에 뜨는 그거, 이름이 뭐더라? 🤔

AI랑 개발하면서 제일 답답했던 건 코드가 아니라 '이름'이었어요.
"화면 아래에서 반쯤 올라오는 창 있잖아..." 하고 열심히 설명하면 AI는 엉뚱한 팝업을 만들어 오고,
"아니 그게 아니라,,"를 몇 번이나 반복했어요.
알고 보니 "Bottom Sheet"라고 한 마디면 끝났을 일이더라고요.

그래서 오늘은 화면 위에 떠서 나오는 UI 5개를 공부해서 정리했어요 📒

🪟 Modal (모달): 화면 가운데 뜨는 창. 닫기 전엔 뒤를 못 눌러요
📥 Bottom Sheet (바텀 시트): 화면 아래에서 올라오는 창. 반만 올라올 수도 있어요
🍔 Drawer (드로어): 옆에서 서랍처럼 밀려 나오는 메뉴
🍞 Toast (토스트): 잠깐 떴다가 저절로 사라지는 짧은 알림
💬 Tooltip (툴팁): 마우스를 올리거나 포커스하면 뜨는 작은 설명 말풍선

장마다 "잘못된 설명" vs "용어를 알고 난 후" 프롬프트도 같이 넣어뒀어요.
8번째 장 정리표는 헷갈릴 때 꺼내 보기 좋아요.
