# AI가 알아먹는 UI 용어집 4탄 캡션

같은 자리에서 바꿔 보는 그 칸, 이름이 뭐더라? 🤔

AI랑 개발하면서 제일 답답했던 건 코드가 아니라 '이름'이었어요.
"같은 자리에서 내용만 바꿔 보는 칸 만들어줘" 하고 열심히 설명하면 AI는 아래로 줄줄이 펼쳐지는 목록을 만들어 오고,
"아니 그게 아니라,,"를 몇 번이나 반복했어요.
알고 보니 "Tab"이라고 한 마디면 끝났을 일이더라고요.

그래서 오늘은 넘기고 펼치는 UI 5개를 공부해서 정리했어요 📒

🗂️ Tab (탭): 같은 자리에서 내용을 바꿔 보는 칸
📂 Accordion (아코디언): 누르면 아래로 펼쳐지는 목록. FAQ에 자주 써요
🎠 Carousel (캐러셀): 옆으로 넘겨 보는 배너나 슬라이드
🔢 Pagination (페이지네이션): 1, 2, 3처럼 페이지 번호로 나눠 보는 칸
🍔 Hamburger Menu (햄버거 메뉴): 줄 세 개 아이콘을 눌러 여는 메뉴

장마다 "잘못된 설명" vs "용어를 알고 난 후" 프롬프트도 같이 넣어뒀어요.
8번째 장 정리표는 헷갈릴 때 꺼내 보기 좋아요.
