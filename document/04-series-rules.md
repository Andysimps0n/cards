# 「AI한테 이렇게 말해」 시리즈 규칙

> 2026-10-03 확정. 모든 편(1탄, 2탄, …)에 공통으로 적용해요.
> 편마다 쓰는 `brief.md`보다 이 문서가 우선이에요.

---

## 1. 커버 제목

- 형식: `AI가 알아먹는 UI 용어집 N탄`
  - 예: 1탄은 위에 떠서 나오는 것들, 2탄은 Header·Footer
- 편의 주제는 제목이 아니라 부제에 써요
- 제목과 부제는 세로 가운데에 둬요
- 키커, 보물 메모, "밀어서 퀘스트 시작 →"는 넣지 않아요

---

## 2. 채팅 카드 (02장)

- 제목: `이런 상황이 답답하시죠,,` (지도 아이콘과 같은 줄)
- 대화는 **항상 두 번 주고받아요**
  - 나 → AI → 나 → AI → 반복 표시 → 나 `"아니 그게 아니라,,"`
- 크기는 #01 값을 따라요
  - 말풍선 30px, AI 말풍선 28px, 원 56px, 미니 목업 0.22배, 결론 카드 44px
- 채팅 장면은 일반적인 상황으로 두고, 실제/예시 여부 주석은 넣지 않아요.

---

## 3. 용어 · 구역 카드

- 용어(또는 구역)를 소개하는 카드에는 **"언제 쓰는지" 한 문장**을 꼭 넣어요 (`term-when`)
- 단계 라벨은 짧게 써요: 구역 편은 `구역 ①`~`구역 ⑤`, 용어 편은 `UI 용어 ①`~`UI 용어 ⑤`
  - 카드의 큰 제목은 용어(또는 구역) 이름이에요. 라벨 뒤에 "첫 번째 지점" 같은 꾸밈말을 붙이지 않아요
- `QUEST #` 번호, 배지, 진행 루트(점 5개)는 넣지 않아요
  - 오른쪽 위 아이콘만 남겨요

---

## 4. 비교 카드

- before/after 박스 라벨: `잘못된 설명` / `용어를 알고 난 후`
- 정리표가 있으면 "이름 | 기능" 두 칸으로 쓰고, 아래 주석은 넣지 않아요
- 정리표 장의 단계 라벨은 `한 눈에 정리`

---

## 5. 마지막 장: 공부 노트형

- 모험·퀘스트 표현은 쓰지 않아요
  - 금지어와 바꿔 쓰는 말은 7장 "말투 규칙"을 따라요
- 구성

| 자리 | 문구 |
|---|---|
| 스탬프 | `오늘 배운 단어 5개` |
| 제목 | `오늘의 정리` |
| 부제 | `저장해두고 AI한테 써먹어보세요` |
| 칩 제목 | `✦ 이제 이렇게 말해요` (칩 = 그 편의 단어들) |
| 다음 편 라벨 | `다음 편` |
| 다음 편 제목 | `<주제> 편` + 설명 2줄 |
| CTA | `🔖 저장하고 써먹기` / `👀 팔로우하고 다음 편 보기` |
| 메모 | `다음 편에서 만나요!` |

- 그림은 지도·깃발·점선 루트 대신 노트나 체크 표시 낙서로 그려요
  - 크레파스 질감은 장식에만 쓰고, 글자는 항상 선명하게 둬요

---

## 6. 주제 규칙

- 한 편은 하나의 테마를 다뤄요
- Header, Footer, Hero Section 같은 페이지 구역도 다뤄요 ("구역 편")
  - `01-design-principles.md`의 "페이지 뼈대 테마 영구 제외" 규칙은 폐지됐어요

---

## 7. 말투 규칙 (2026-10-03 확정)

카드에 들어가는 모든 글자와 캡션은 **공부 노트 말투**로 써요. 모험·퀘스트 말투는 쓰지 않아요.

### 말투 특징
- 친근한 존댓말(해요체). 반말은 쓰지 않아요
- 선생님이 아니라 **같이 배우는 동료**가 "제가 공부해봤는데요" 하고 알게 된 걸 나누는 느낌
- 문장은 짧게. 한 문장에 한 가지만 말해요
- 단계 라벨은 짧게: 구역 편은 `구역 ①`, 용어 편은 `UI 용어 ①` (뒤에 "첫 번째 지점" 같은 꾸밈말을 붙이지 않아요)

### 쓰지 않는 말
`퀘스트`, `QUEST 클리어`, `주문` / `주문서`, `탐험`, `모험`, `지점`, `보물`, `NEXT QUEST`

### 바꿔 쓰는 말

| 쓰지 않는 말 | 이렇게 바꿔요 |
|---|---|
| 퀘스트 완료! | 오늘의 정리 |
| QUEST #01 클리어! | 오늘 배운 단어 5개 |
| 주문, 주문서 | 말, 프롬프트 |
| 오늘 얻은 주문 5개 | 이제 이렇게 말해요 |
| 다음 지점에서 만나요 | 다음 편에서 만나요 |
| NEXT QUEST #02 | 다음 편 |
| 팔로우하고 같이 탐험 | 팔로우하고 다음 편 보기 |
| 용어 ① 첫 번째 지점 | UI 용어 ① / 구역 ① |
| 보물: ○○ | (넣지 않음) |

### 그림과 말투는 따로
- 크레파스 질감, 지도 모눈 배경, 점선 같은 **그림 스타일은 장식으로 남아도 돼요**
- 다만 카드 글자와 캡션에는 모험 표현을 쓰지 않아요
- 시리즈 코드 이름(`series="talk"`, `QuestTag` 같은 컴포넌트 이름)은 코드 안 이름이라 그대로 둬도 돼요. 화면에 보이는 글자만 이 규칙을 따라요
