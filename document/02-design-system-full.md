# 크레파스 모험일지 디자인 시스템 v0.1 (초안)

> 공부하는 개발자의 탐험 기록을 **파스텔 크레파스로 그린 모험 지도**처럼 보여주는 시스템

---

## 1. 콘셉트

- **한 줄 정의**: "도화지에 크레파스로 그린 보물지도 위에서, 한발 앞서 걸어본 동료가 길을 알려주는 계정"
- **키워드**: 모험일지 · 보물지도 · 퀘스트 · 크레파스 · 파스텔 · 장난스러움
- **원칙 3가지**
  1. **질감은 장식에만**: 크레파스 질감은 배경 도형, 테두리, 배지, 루트선, 형광펜에만 써요. 글자는 언제나 선명하게
  2. **판타지보다 피드**: 양피지·고딕 장식처럼 무거운 판타지는 피하고, 여백 많은 밝은 종이 위에 장식 몇 개만 둬요
  3. **게시물 하나 = 퀘스트 하나**: 커버 = 퀘스트 수락, 본문 = 지점 탐험, 엔딩 = 퀘스트 클리어 + 다음 퀘스트 예고

## 2. 컬러 팔레트

### 종이 (배경)
| 토큰 | HEX | 용도 |
|---|---|---|
| `--paper` | `#FFF9F0` | 기본 배경 (크림색 도화지) |
| `--paper-warm` | `#FBEFDD` | 카드 안쪽, 프롬프트 박스, 지도 종이 |
| `--paper-line` | `#EFE2CC` | 배경 점 모눈, 구분선 |

### 잉크 (글자)
| 토큰 | HEX | 용도 |
|---|---|---|
| `--ink` | `#3D3654` | 제목·본문. 순검정 대신 보라빛 남색으로 파스텔과 어울리게 |
| `--ink-soft` | `#7A7291` | 부제, 설명, 푸터 |
| `--ink-faint` | `#B9B1C9` | 비활성, 자리표시, 점선 |

### 필러 색 (크레파스) — 시리즈 구분의 핵심
| 필러 | 파스텔 (면) | 진한 색 (글자·선) | 별명 |
|---|---|---|---|
| 🎨 UI/UX | `#F9B4C4` | `#D9637F` | 딸기우유 핑크 |
| 🤖 AI | `#A9D3F5` | `#3F82C0` | 소다 하늘색 |
| 🧭 개발 일상 | `#B4E3BE` | `#3E9960` | 새싹 민트 |

- 파스텔은 **면**(배경 덩어리, 배지, 칩, 카드 테두리)에, 진한 색은 **작은 글자·선**(QUEST 번호, 루트 점선, X 표시)에 써요
- 파스텔 위에 흰 글자는 쓰지 않아요 (대비 부족). 파스텔 위 글자는 항상 `--ink`

### 공용 포인트
| 토큰 | HEX | 용도 |
|---|---|---|
| `--sun` / `--sun-deep` | `#FFE08A` / `#E0A722` | 형광펜 하이라이트, 별, 클리어 스탬프 (필러와 무관하게 공통) |
| `--lilac` | `#D2C2F5` | 보조 장식 (예: 「만약에 UI」의 구름·별 장식) |
| `--peach` | `#FFC9A3` | 보조 장식, 일러스트 |

**비율 가이드**: 종이 70% · 필러 파스텔 20% · 잉크 8% · 노랑 포인트 2%

## 3. 타이포그래피

모두 무료 폰트예요. Jua, Gaegu, JetBrains Mono는 Google Fonts, Pretendard는 GitHub(orioncactus/pretendard)에서 받을 수 있어요. 파일은 `fonts/` 폴더에 넣어 뒀어요.

| 역할 | 폰트 | 굵기 | 크기 (1080 기준) | 쓰는 곳 |
|---|---|---|---|---|
| Display | **Jua (주아)** | 400 (단일 굵기) | 커버 128 / 카드 제목 84~120 / 소제목 56 | 커버 제목, 용어명, 칩, 배지 옆 시리즈명 |
| Hand (손글씨) | **Gaegu (개구)** | 700 (300·400도 있음) | 34~48 | 지도 위 메모, 퀘스트 타입, "밀어서 퀘스트 시작", 푸터 |
| Body | **Pretendard** | 500 / 600 / 800 | 본문 36~40, 최소 28 | 설명, 뜻 풀이, 프롬프트 한국어 |
| Mono | **JetBrains Mono** | 500 / 800 | 24~36 | `QUEST #01`, 페이지 번호, 영문 용어, 코드 |

- Jua는 둥글고 굵은 손글씨 느낌이라 크레파스 무드와 잘 맞고, 작은 썸네일에서도 잘 읽혀요
- Gaegu는 획이 가늘어서 **32px 아래로는 쓰지 않기**. 긴 문장 말고 짧은 메모에만
- JetBrains Mono에는 한글이 없어요. 한글이 섞이면 Pretendard로 자동 대체되게 지정해 뒀어요
- 줄간격: 제목 1.2 / 본문 1.55. 자간: 제목 -0.01em
- `word-break: keep-all`로 한국어 단어가 중간에 끊기지 않게

## 4. 레이아웃 & 그리드 (1080 × 1350, 4:5)

- **기본 단위 8px** (간격: 8 / 16 / 24 / 32 / 48 / 64)
- **여백**: 위 96 · 좌우 88 · 아래 104
  - 프로필 그리드는 게시물을 3:4(약 1012×1350)로 잘라 보여줘요. 좌우가 34px씩 잘리니 좌우 88px이면 안전해요
- **푸터 고정**: 바닥에서 52px 위에 `@계정명`(Gaegu) + `03 / 09`(Mono)
- **세로 흐름**: 위 → 아래로 "배지 → 제목 → 내용 → 다음 행동" 순서 고정
- **모서리**: 카드 36px, 프롬프트 박스 28px, 칩은 완전 둥글게
- **본문 최소 크기**: 28px (휴대폰에서 읽히는 하한선)

## 5. 모티프 & 아이콘

크레파스 질감은 SVG 필터 3종으로 만들어요 (`assets/crayon.js`).

| 필터 | 효과 | 쓰는 곳 |
|---|---|---|
| `#wax` | 울퉁불퉁한 가장자리 + 왁스 입자 | 배경 덩어리, 배지 원, 칩, 형광펜, 카드 테두리 |
| `#wax-stroke` | 가는 흔들림 + 끊기는 선 | 아이콘 선, 루트 점선, 스탬프 테두리 |
| `#rough` | 흔들림만 (질감 없음) | 프롬프트 박스 점선 테두리 |

**아이콘 세트** (손그림 선, 100×100, `Crayon.icon(name)`):
`compass`(나침반) · `map`(지도) · `pin`(핀) · `x`(보물 위치) · `flag`(깃발) · `key`(열쇠) · `star`(별) · `arrow`(화살표) · `scroll`(주문서) · `magnifier`(돋보기) · `cloud`(상상 구름) · `telescope`(망원경) · `dice`(주사위)

**고정 모티프**
- **점선 루트**: 커버 하단에서 X 표시(목적지)까지 이어지는 진한 필러색 점선
- **X 표시 + 손글씨 메모**: "보물: ○○" 형식으로 이번 게시물에서 얻을 것을 한 줄로
- **진행 루트**: 콘텐츠 카드 오른쪽 위 점 5개, 현재 지점만 크게 칠하기
- **클리어 스탬프**: 엔딩 카드의 노란 원형 도장
- **배경 점 모눈**: 48px 간격의 연한 점 (지도 모눈 느낌)

## 6. 시리즈 = 퀘스트 타입

필러 색으로 큰 분류를, **배지 아이콘**으로 시리즈를 구분해요. 번호는 시리즈마다 따로 매겨요.

| 필러 | 시리즈 | 퀘스트 타입 | 배지 아이콘 | 코드 키 |
|---|---|---|---|---|
| 🎨 UI/UX | 「AI한테 이렇게 말해」 | 주문서 퀘스트 | 주문서 (scroll) | `talk` |
| 🎨 UI/UX | 「이 디자인 왜 예쁨?」 | 탐사 퀘스트 | 돋보기 | `why` |
| 🎨 UI/UX | 「만약에 UI」 | 상상 퀘스트 | 구름+별 | `whatif` |
| 🤖 AI | 「이번 주 AI」 | 소식 퀘스트 | 망원경 | `weekly` |
| 🤖 AI | 「이것도 AI로 돼?」 | 발견 퀘스트 | 열쇠 | `cando` |
| 🧭 개발 일상 | 「개발 모험일지」 | 메인 퀘스트 | 깃발 | `log` |
| 🧭 개발 일상 | 「주간 쓸모없는 앱」 | 챌린지 퀘스트 | 주사위 | `silly` |

- **번호 표기**: `QUEST #01` (두 자리, JetBrains Mono 800, 진한 필러색)
- 「개발 모험일지」의 계정 소개편은 `QUEST #00`
- **배지 구성**: 파스텔 원(크레파스) + 진한 색 점선 링 + 잉크색 아이콘

## 7. 캐러셀 템플릿

| 템플릿 | 파일 | 구성 |
|---|---|---|
| 커버 | `templates/cover.html` | 퀘스트 배지 + 번호 → 손글씨 키커 → 큰 제목(핵심 단어 노란 형광펜) → 부제 → "밀어서 퀘스트 시작 →" → 점선 루트 + X + "보물: ○○" |
| 콘텐츠(용어) | `templates/term.html` | 작은 배지 + 진행 루트 → "용어 ① 첫 번째 지점" → 용어(Jua 120) + 영문(Mono) → 뜻 2줄 → 나쁜 예/좋은 예 미니 카드 → "AI한테 이렇게 말해" 프롬프트 박스 |

**9장 캐러셀 기본 순서**: 커버 → 문제 제기 → 콘텐츠 ×5 → Before/After → 엔딩

## 8. 릴스 커버 규칙

- 1080×1920(9:16)로 만들되, **핵심 제목·배지는 가운데 1080×1440(3:4) 안에** 두기 (프로필 그리드에서는 가운데만 보여요)
- 캐러셀 커버와 같은 구조: 배지 + 큰 제목 + 형광펜 + 필러색 덩어리
- 영상 첫 프레임과 커버를 맞추면 피드에서도 같은 시리즈로 보여요
- 위아래 여백에는 장식(루트, 별)만 두고 글자는 두지 않기

## 9. 프로필 그리드 가이드

- **색 리듬**: 같은 필러가 가로로 붙지 않게 핑크 → 하늘 → 민트를 대각선으로 번갈아 배치
- **같은 뼈대**: 모든 커버는 배지 위치·제목 위치·덩어리 위치가 같아서, 썸네일만 봐도 이 계정 게시물로 보여요
- **제목은 3줄 이하, 한 줄 6자 안팎**: 썸네일에서 읽히는 한계
- **첫 9개 순서 예시** (목업 `07-profile-grid.png`, 최신이 왼쪽 위):
  - 1주차: 「AI한테 이렇게 말해」 #01 → 「이것도 AI로 돼?」 #01 → 「개발 모험일지」 #00
  - 이후: 「만약에 UI」, 「주간 쓸모없는 앱」, 「이번 주 AI」 등을 필러가 섞이게
  - ※ 목업의 #01 이후 제목은 배치 확인용 예시예요

## 10. Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| 크레파스 질감은 배경 덩어리·테두리·배지·선에만 | 본문 글자에 질감이나 흔들림 필터 넣기 |
| 글자는 `--ink`로, 파스텔 위에도 진한 잉크 | 파스텔 위 흰 글자, 연한 색 위 연한 글자 |
| 한 장에 장식 3~4개 (덩어리 1 + 루트 1 + 아이콘 1~2) | 별·지도·나침반·스티커를 한 장에 잔뜩 |
| 형광펜은 한 제목에 한 단어만 | 모든 줄에 형광펜 |
| 본문 28px 이상, 한 장에 핵심 하나 | 작은 글씨로 설명 꽉 채우기 |
| 필러 색을 시리즈 구분에 일관되게 | 게시물마다 색을 바꿔서 시리즈를 헷갈리게 |
| 양피지 대신 밝은 크림 도화지 | 진한 갈색 양피지, 고딕 판타지 폰트 |
| Gaegu는 짧은 메모에만 (32px 이상) | Gaegu로 긴 본문 쓰기 |

## 11. 파일 구조 & 새 게시물 만드는 법

```
insta-design-system/
├─ design-system.md
├─ fonts/                    # Jua, Gaegu, Pretendard, JetBrains Mono
├─ templates/
│  ├─ assets/tokens.css      # 색·폰트·간격 토큰 (CSS 변수)
│  ├─ assets/base.css        # 공용 컴포넌트 (.hl, .chip, .card, .prompt, .quest-tag ...)
│  ├─ assets/crayon.js       # 크레파스 필터, 아이콘, 시리즈 데이터, URL 파라미터 바인딩
│  ├─ cover.html · term.html · before-after.html · ending.html
│  └─ specimen.html · grid.html
├─ render.sh                 # HTML → PNG (headless Chrome)
├─ build.py                  # 미리보기 일괄 생성
└─ previews/*.png
```

- 모든 텍스트에는 `data-field="이름"`이 붙어 있어서 URL 파라미터로 바꿀 수 있어요
- `series=talk|why|whatif|weekly|cando|log|silly` 하나만 바꾸면 색·배지·시리즈명·퀘스트 타입이 자동으로 바뀌어요
- 예시:
  ```bash
  ./render.sh templates/cover.html previews/new.png \
    "series=why&no=1&kicker=탐사%20시작&title=이%20디자인%3Cbr%3E왜%20예쁨%3F"
  ./render.sh templates/term.html previews/term2.png "series=talk&no=1&step=2&term=시각적%20위계&en=Visual%20Hierarchy"
  ```
- 색이나 폰트를 바꾸려면 `tokens.css`만 고치면 돼요
